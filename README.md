# Social-Media-Viral-Content-Analysis-using-SQL
This project analyzes a Social Media Viral Content dataset using SQL to understand what makes posts go viral.   The analysis focuses on platform performance, content type, topic trends, regional engagement, and sentiment impact.  A SQL View was created and connected to Power BI to build a dashboard from the database directly.

**Key Analysis**
- Platform-wise viral performance
- Topic-wise viral posts
- Region-wise engagement
- Sentiment impact on virality
- Top 10 engaging posts
